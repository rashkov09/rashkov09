## How I work

My background in application support strongly influences how I build software:

- failures should be visible, not silently converted into success;
- important decisions should be traceable to exact evidence;
- deployments should be reproducible and reversible;
- automation should reduce manual work without removing human control;
- AI agents should operate inside clear technical and review boundaries.

I use AI heavily in development, but not as a substitute for engineering controls. Implementation, independent review, deterministic CI, exact-version evidence, and human approval are treated as separate concerns.
